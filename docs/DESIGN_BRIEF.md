# Brightdesk Planner — product design brief

## Purpose
A local-first project planner for turning plans into visible stages, responsibilities and progress.

## Core experience
- Multiple plans with clear plan navigation.
- Board view with custom buckets and cards.
- Timeline and progress summaries.
- Priority, due date and status information.
- Search and filters without losing task context.

## Visual direction
Use the shared Brightdesk shell with a royal-blue Planner accent. Provide a calm board canvas, distinct status columns, compact cards, clear metadata chips and consistent creation actions. Support responsive board scrolling and keyboard-friendly editing.

## Status
**Scaffold only.** This repository currently contains visual assets and a design brief; it does not yet contain runnable application source, a package manifest or a desktop build. The README preview is a design target, not an implemented screen.
